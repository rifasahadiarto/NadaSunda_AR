# NadaSunda AR

NadaSunda AR is a Unity augmented reality project for exploring traditional Sundanese musical instruments in a real-world setting.

Users can scan a flat surface, place instrument models, switch between placed instruments, and interact with them to hear their sounds.

## Instruments

- Angklung
- Saron
- Kendang
- Kacapi
- Goong

## Built with

- Unity 2022.3.62f3
- AR Foundation 5.1.5
- ARCore XR Plugin 5.1.5
- C#

## Open the project

1. Open the project folder in Unity Hub with Unity 2022.3.62f3.
2. Open `Assets/Scenes/MainMenu.unity`.
3. Run in the Unity Editor with XR Simulation, or build for an ARCore-supported Android device.

The first AR session needs camera permission and a detected flat surface.

## Repository contents

This repository contains the Unity project assets, packages, project settings, and source assets. Unity-generated folders and local build output are excluded through `.gitignore`.
